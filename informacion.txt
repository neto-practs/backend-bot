Para que el frontend active el modo WhatsApp o muestre sugerencias, el backend debe devolver un objeto JSON con las siguientes
  propiedades clave:

  1. Para activar el botón de WhatsApp
  Tienes dos formas de activarlo (ambas funcionan con el código actual):

   * Opción A (Nueva - Recomendada): Usar la bandera pedirWhatsapp.

   1     {
   2       "respuesta": "Lo sentimos, no hay stock de esa pieza...",
   3       "pedirWhatsapp": true
   4     }
      El frontend añadirá automáticamente el botón al final del mensaje.

   * Opción B (Explícita): Incluir la etiqueta [[WHATSAPP]] en cualquier parte del texto.

   1     {
   2       "respuesta": "Contacta con nosotros aquí: [[WHATSAPP]]"
   3     }

  ---

  2. Para mostrar Sugerencias (Botones de respuesta rápida)
  El backend debe enviar un array de strings en la propiedad sugerencias.

   * Formato esperado:

   1     {
   2       "respuesta": "¿Qué marca es tu coche?",
   3       "sugerencias": ["BMW", "Audi", "Mercedes", "Toyota"]
   4     }
      El frontend convertirá automáticamente cada elemento del array en un botón seleccionable para el usuario.
